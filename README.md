# Mariam Anwer — Portfolio

React + Vite portfolio. All content lives in `src/data.js`; styles in `src/style.css`.

## Run locally
```
npm install
npm run dev
```

## Deploy on GitHub Pages
1. Push this folder to a GitHub repository (branch `main`).
2. In the repository go to Settings → Pages → Source and choose **GitHub Actions**.
3. Each push to `main` builds and publishes the site.
